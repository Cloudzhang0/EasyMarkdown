# EasyMarkdown

轻量级 Markdown 编辑器，支持网页版和桌面版，实时预览，纯静态部署，无需服务端。

## 功能特性

### 核心功能
- 左右分栏布局，实时 Markdown 预览
- 支持 GFM（GitHub Flavored Markdown）
- 代码语法高亮（支持 50+ 种编程语言）
- Mermaid 图表渲染（流程图、时序图、甘特图等）
- LaTeX 数学公式渲染（KaTeX）
- 格式化工具栏（16+ 个快捷按钮）
- **多标签页**：同时打开多个 Markdown 文件，点击标签切换
- 文件管理（新建、打开、保存、另存为、关闭）
- 最近打开文件列表（点击直接切换到已打开的文件）
- 自动保存到浏览器本地存储（localStorage）
- 导出为 HTML 和 PDF
- 打印支持
- 12 种语言切换
- 浅色/深色主题切换
- 键盘快捷键支持
- 响应式布局（最小支持宽度 768px）
- XSS 安全过滤（DOMPurify）

### 桌面版特有功能（Electron）
- **文件树侧边栏**：打开文件夹后显示目录结构
- **文件树右键菜单**：
  - 新建文件/文件夹
  - 复制路径
  - 在资源管理器中打开
  - 重命名/删除
  - 刷新文件树
- **编辑器右键菜单**：
  - 剪切/复制/粘贴/全选
  - 撤销/重做
  - 大小写转换
  - 搜索选中文本
  - 插入时间戳/分割线
  - **语音输入**（支持中文）
  - 滚动到预览位置
- 原生文件对话框
- 窗口状态记忆
- 原生菜单栏集成

## 使用方式

### 网页版

```bash
cd web
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

或直接用浏览器打开 `index.html` 文件（部分功能可能受限）。

### 桌面版

```bash
cd desktop
npm install
npm start
```

构建安装包：
```bash
npm run build:win    # Windows
npm run build:mac    # macOS
npm run build:linux  # Linux
```

### 部署到服务器

将 `web/` 目录下的所有文件部署到任意静态文件服务器或 CDN。

无需服务端运行时，所有功能均在浏览器中完成。

## 测试方法

### 基础功能测试

1. 启动服务器：`cd web && python -m http.server 8080`
2. 浏览器访问 `http://localhost:8080`（建议 Ctrl+Shift+R 强制刷新）
3. 逐项验证：

| 测试项 | 操作 | 预期结果 |
|--------|------|----------|
| 编辑器输入 | 在左侧编辑区输入文字 | 文字正常显示，无延迟 |
| 实时预览 | 输入 `# 标题` | 右侧预览区显示 H1 标题 |
| 代码高亮 | 输入带语言标识的代码块 | 代码有语法高亮 |
| 菜单系统 | 点击"文件"菜单 | 下拉菜单正常显示所有选项 |
| 新建文件 | 文件 → 新建 | 创建新标签页 |
| 多标签页 | 新建多个文件，点击标签切换 | 各标签内容独立保存 |
| 关闭标签 | 点击标签上的 × 按钮 | 关闭当前标签 |
| 打开文件 | 文件 → 打开文件 | 选择 .md 文件后在新标签打开 |
| 保存文件 | Ctrl+S | 触发浏览器下载 |
| 语言切换 | 右上角选择"English" | 所有界面切换为英文 |
| 主题切换 | 视图 → 切换主题 | 背景变深色/浅色 |
| 格式化 | 选中文本，点击粗体按钮 | 文本被 `**...**` 包裹 |
| 状态栏 | 查看底部状态栏 | 显示文件名、字数、光标位置 |
| 帮助系统 | 帮助 → 语法速查表 | 弹窗显示语法参考 |

### 多标签页测试

1. 打开编辑器，默认显示一个"未命名"标签
2. 文件 → 新建，出现第二个标签
3. 在第一个标签输入内容，切换到第二个标签
4. 切回第一个标签，内容应保留
5. 编辑内容后标签显示脏标记（圆点）
6. 关闭标签，自动切换到相邻标签
7. 关闭最后一个标签，自动创建新的空标签
8. 刷新页面，标签和内容应恢复

## 技术栈

- **编辑器**: CodeMirror 5
- **Markdown 解析**: marked.js（GFM）
- **代码高亮**: highlight.js
- **XSS 防护**: DOMPurify
- **图表渲染**: Mermaid
- **数学公式**: KaTeX

## 浏览器兼容性

支持主流现代浏览器：

- Google Chrome（最新版及近两个大版本）
- Mozilla Firefox（最新版及近两个大版本）
- Microsoft Edge（最新版及近两个大版本）
- Safari（最新版及近两个大版本）

## 数据隐私

所有用户编辑内容仅在本地浏览器中处理，不上传至任何远程服务器。数据存储在浏览器本地存储（localStorage）中。

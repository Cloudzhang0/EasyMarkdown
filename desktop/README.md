# EasyMarkdown 桌面版

基于 Electron 框架构建的跨平台桌面 Markdown 编辑器，支持 Windows、macOS、Linux。

## 功能特性

在网页版全部功能的基础上，额外提供：

- 原生文件系统读写（直接保存到磁盘）
- 打开文件夹，侧边栏树形结构展示 Markdown 文件
- 原生系统文件对话框
- 最近打开文件列表（点击直接打开文件）
- 从系统文件管理器拖放文件到应用窗口
- 窗口位置和大小记忆
- 原生应用菜单
- 本地图片文件选择（自动复制到 images 子目录）
- 自动保存（300ms 防抖延迟）
- 多标签页（同时打开多个文件）
- 文件菜单"退出"按钮

## 安装与运行

### 前置要求

- Node.js 16+
- npm 或 yarn

### 安装依赖

```bash
cd desktop
npm install
```

### 启动应用

```bash
npm start
```

### 打包构建

```bash
# Windows
npm run build:win

# macOS
npm run build:mac

# Linux
npm run build:linux
```

构建产物将输出到 `dist/` 目录。

## 文件结构

```
desktop/
├── package.json    # 项目配置和构建脚本
├── main.js         # Electron 主进程（窗口管理、文件操作、菜单）
└── preload.js      # 预加载脚本（上下文隔离，安全 IPC）
```

## 技术架构

### 主进程 (main.js)

- 窗口创建和管理
- 原生菜单构建
- 文件系统操作（读取、写入、目录遍历）
- IPC 通信处理（包括退出应用）
- 最近文件管理
- 窗口状态持久化

### 预加载脚本 (preload.js)

- 通过 `contextBridge` 安全暴露 IPC 方法
- 启用上下文隔离（Context Isolation）
- 禁用 Node.js 集成（安全性）
- 暴露 `exitApp` 方法用于退出应用

### 渲染进程

复用 `web/` 目录下的全部前端代码，通过 `desktop-bridge.js` 模块与主进程通信。

## 安全性

- 启用上下文隔离，渲染进程无法直接访问 Node.js API
- 文件系统操作通过 IPC 桥接，限制在用户明确选择的目录范围内
- 预加载脚本仅暴露必要的 API 方法
